# paperswithcode.com — SOTA Leaderboards

- Leaderboards are organized by **task** (e.g. "Image Classification on ImageNet") not by paper — start from the task and dataset that matches the actual problem, rather than searching for a specific paper first
- Each leaderboard row links directly to its paper *and* its code implementation(s) when available — this is the site's main advantage over arXiv alone, since a SOTA claim with no linked code (or only unofficial reimplementations) is a weaker basis for reuse than one with an official release
- The same task often has multiple leaderboards keyed to different benchmark datasets (e.g. several datasets under "Question Answering") — results only compare validly within the same dataset/metric combination, not across them
- A method's own page (distinct from a specific paper) aggregates every paper that used it and every dataset it's been evaluated on — useful for judging whether a technique generalizes across tasks or was only ever tested once
- Rankings and linked repos go stale between site updates faster than the underlying research moves — treat the current top-of-leaderboard entry as a strong candidate to verify (check the linked repo's last-updated date and open issues) rather than a final answer
