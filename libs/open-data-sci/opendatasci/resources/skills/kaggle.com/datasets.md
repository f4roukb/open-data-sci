# kaggle.com — Datasets Catalog

- The **Datasets** tab (separate from Competitions) hosts standalone data with its own votes/usability score and a "Data Card" describing provenance and licensing — check the license before reuse in non-competition work
- A dataset's "Usability" score and download/vote counts are a quick proxy for data quality and community vetting when triaging many candidate datasets quickly
- The Data Card's "Collection Methodology" and "Provenance" sections (when present) determine whether a dataset is safe to generalize from, or is a scraped/synthetic sample with narrower external validity than it appears
- Multiple dataset versions can exist under one listing — check the version history for schema or label changes before assuming a downloaded copy matches what a linked notebook expects
