# huggingface.co Skill Domain

Curated entry points into huggingface.co — rankings, available checkpoints, and active leaderboard Spaces shift often enough that general knowledge goes stale fast. Load a skill here when picking a model rather than relying on trained-in knowledge of what was state of the art.

## Leaderboards

- skill: huggingface.co::leaderboards

Which Hugging Face Spaces leaderboard to check for a given model category (text embedding, general LLM, ASR, TTS, vision-language, code generation), how to filter each for hardware fit, and how to translate a leaderboard entry into a memory/compute estimate; load before picking a model to run locally or in a resource-constrained environment.
