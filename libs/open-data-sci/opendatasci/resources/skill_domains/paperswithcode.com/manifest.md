# paperswithcode.com Skill Domain

Curated entry points into paperswithcode.com — it links SOTA claims to running code, which is the piece the `arxiv.org` domain alone doesn't give. Load a skill here when the goal is finding a reproducible state-of-the-art method for a task, not just reading about one.

## SOTA Leaderboards

- skill: paperswithcode.com::sota_leaderboards

How to navigate task/dataset-scoped leaderboards, use linked code to judge reproducibility, and avoid comparing results across incompatible benchmark datasets; load when picking a method or model for a specific task rather than a specific paper.
