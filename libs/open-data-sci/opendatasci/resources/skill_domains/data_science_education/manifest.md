# Data Science Education Skill Domain

A playbook for teaching data science and statistics: reading what a learner already knows, building intuition before formalism, structuring explanations, using worked examples well, calibrating depth to the audience, correcting misconceptions, and connecting new ideas to what the learner already has. Load the skill that matches the moment you're in with the learner.

## Diagnosing Understanding

### Metadata
- skill_domain_name: data_science_education
- skill_name: diagnosing_understanding

### Description
Probing what the learner already knows and believes before explaining, and using concrete questions rather than self-assessments to reveal their actual understanding; load before starting any explanation.

## Building Intuition First

### Metadata
- skill_domain_name: data_science_education
- skill_name: building_intuition

### Description
Leading with intuition and motivating examples before formalism, and using analogies and geometric/visual explanations while flagging where they break down; load when introducing a new concept.

## Structuring Explanations

### Metadata
- skill_domain_name: data_science_education
- skill_name: structuring_explanations

### Description
Moving from concrete to abstract, chunking complex ideas, naming the key idea explicitly, and checking for understanding at intermediate steps; load while planning or delivering the structure of an explanation.

## Worked Examples & Code

### Metadata
- skill_domain_name: data_science_education
- skill_name: worked_examples_code

### Description
Building minimal self-contained examples, annotating code at the conceptual rather than syntactic level, treating common mistakes explicitly, and showing concepts in multiple representations; load when writing a worked example or teaching through code.

## Calibrating Depth to the Learner

### Metadata
- skill_domain_name: data_science_education
- skill_name: calibrating_depth

### Description
Matching explanation depth to whether the learner needs to use or extend a technique, defining jargon on first use, reading signals that a learner is ready for more depth, and being honest about genuine complexity; load when deciding how much detail to give.

## Feedback & Correction

### Metadata
- skill_domain_name: data_science_education
- skill_name: feedback_correction

### Description
Explaining why a misconception is appealing and where it fails rather than just stating the right answer, reinforcing correct reasoning, asking learners to restate concepts, and giving hints rather than solutions when they're stuck; load when responding to a learner's answer or mistake.

## Connecting Concepts

### Metadata
- skill_domain_name: data_science_education
- skill_name: connecting_concepts

### Description
Relating new concepts to ones the learner already understands, situating a concept within its broader framework, pointing out when two ideas are the same thing in disguise, and flagging common confusions between related concepts; load when a concept is best taught in relation to others.
