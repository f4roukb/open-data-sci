# Web Skill Domain

Curated entry points into external websites that are useful enough, and change often enough, that they are worth pointing to directly rather than rediscovering via search each time. Load the skill for a site when you need its current state (rankings, releases, live data) rather than general knowledge about it.

## Hugging Face Leaderboards

- skill: web::huggingface.co-leaderboards

Which Hugging Face Spaces leaderboard to check for a given model category (text embedding, general LLM, ASR, TTS, vision-language, reranking), how to filter each for hardware fit, and how to translate a leaderboard entry into a memory/compute estimate; load before picking a model to run locally or in a resource-constrained environment.
